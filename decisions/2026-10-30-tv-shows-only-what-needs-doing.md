# 2026-10-30 The TV shows only what still needs doing, named from OnSinch

**Decided by:** the owner (29 and 30 Oct), after the card-by-card check of the TV (ADDENDUM §13).

**Rulings.**
1. **A job whose days have all passed never appears on the TV** (29 Oct): "jobs that have already passed should not
   appear there. This is a rule alongside checking for updates as far as what should appear in the list."
2. **A need staff have already handled in OnSinch leaves the needs list** (the same message: "checking for updates").
3. **A card's name** (30 Oct): "when a card is linked to an order, the name should be the OnSinch order title if it's
   available. If it's not available, it should be the client and venue. If the client and venue is not available, it
   should be the client's sender email ... It should never be an internal Spartan Crew email. It should absolutely
   only be the original sender of the email." A subject line is never a name.
4. **A taller, three-line tile** for the description, accepted by the owner and Paz, with the UI "nice and orderly
   and tight".
5. **A need does not depend on having a day.** A need with no day is still a need, matched to its job by what else
   names it.
6. **Clearing a need on another job's work must be prevented** (staff working another job for the same client on the
   same day).
