# Outcome labels (2 Nov 2026)

`labels.tsv` is every thread in Spartan's bookings mailbox from 30 Jul to 2 Nov 2026 (1,145 threads, 6,729
emails), each read email by email and labelled by hand. A row is one Gmail thread: its types, one code per
email in order (client codes upper case, Spartan's lower case), how the thread ended and flags. The codes are in
`codebook.md`. The rows carry no email text, address or name; the thread id is the only key back to the mail.

The reading was of masked excerpts (names, phones, addresses, links and postcodes replaced; each email cut at 180
characters after greetings and sign-offs were stripped), done by one reader with no second rater. An email whose
point fell past 180 characters may carry the code its first sentences suggest.

What it is for: the measured definition of each email type and the reference answer for the reader's three-way
decision (card, wait, nothing) on the 1,276 client emails that have a stored v2 decision. The findings are
`fleet/resume/Spartan-Outcome-Analysis-2026-11-02.md` and ADDENDUM §15.
